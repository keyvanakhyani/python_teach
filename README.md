# python_teach

Teaching material and worked examples from the Python courses I run privately.

Each folder is a self-contained topic with runnable examples:

- `Function Wrappers` — decorators and wrapping patterns
- `Functions and Class Metadata` — introspection, dunder attributes
- `PyQt6` — desktop GUI examples
- `tkinter` — GUI basics
- `te_requests` — working with HTTP and APIs
- `markdown` — notes and write-ups
